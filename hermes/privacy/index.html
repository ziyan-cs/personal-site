隐私政策

更新日期：2026 年 11 月 16 日。本政策说明 AI Calendar（站点所有者个人使用的 Hermes 日历助手）如何处理通过 Google Calendar API 获取的数据。Hermes 的使用和日历访问均需要账号所有者授权。

访问的数据与用途

在获得 Google 授权后，Hermes 可读取获授权账号的日历及日程信息，包括日历名称、事件标题、时间、地点和描述等，用于回答日程问题、识别安排和提供提醒。根据用户明确要求，Hermes 也可能创建或删除日程；助手的操作约定是在写入前确认具体事项，底层日历工具不会自行再次询问。

当前请求的完整 Google Calendar 权限还允许查看、编辑、分享及永久删除可访问的日历；这是 Google 授权范围，不代表本助手会自动执行这些操作。

数据处理与共享

日历数据用于响应用户的请求和已授权的提醒。为生成回答或发送提醒，完成该功能所需的日程内容可能被发送给所配置的 AI 模型服务或用户选择的消息平台；具体接收方取决于当时启用的服务。Hermes 不将 Google 用户数据用于广告投放、出售给数据经纪商，或用于开发、改进或训练非个性化 AI/机器学习模型。

关于 Google 用户数据处理的适用规则，请参阅 Google API Services User Data Policy，包括其中的有限使用要求。

存储与保留

Google OAuth 凭据保存在运行助手的设备上，用于维持授权；日程内容可能出现在用户请求的对话、提醒、应用状态或日志中。保存时长取决于这些记录的实际保留设置；撤销授权不会自动删除此前已保存的对话或日志。

安全措施

OAuth 凭据使用本机账号的文件权限保护；访问 Google Calendar API 使用 HTTPS。请妥善保护运行助手的设备和授权账号。

撤销与删除

账号所有者可在 Google 账号的第三方连接设置中撤销 Hermes 的访问权限，并可联系站点所有者请求删除本地保存的相关凭据及记录。撤销后，助手不能继续通过该授权访问日历，除非重新授权。
